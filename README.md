# Amalia Madden

A responsive personal website inspired by handmade early-web homepages, with
a tiled animated maneki-neko background, a rainbow navigation rail, and a
sparkling cursor.

## Local development

Requires Node.js 22 and pnpm 11.

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` builds and deploys the
site whenever `main` is pushed. It automatically supports both user sites and
project sites.

The production visitor total uses CountAPI and increments once per browser.
Local development reads the shared total without incrementing it, so previews
do not affect the public count. If the service is temporarily unavailable, the
page falls back to a device-local count.

## Guestbook

The guestbook uses Giscus and stores entries in GitHub Discussions. Enable
Discussions on the public repository, install the Giscus GitHub app, create a
guestbook category, then copy `.env.example` to `.env.local` and fill in the
repository and category IDs generated by [giscus.app](https://giscus.app/).

For GitHub Pages, add the same values under **Settings > Secrets and variables
> Actions > Variables** as `GISCUS_REPO`, `GISCUS_REPO_ID`,
`GISCUS_CATEGORY`, and `GISCUS_CATEGORY_ID`. The deployment workflow exposes
them to the static build.

In the GitHub repository, open **Settings > Pages** and set **Source** to
**GitHub Actions** once. The workflow publishes the static `out/` directory.

Run the same production checks locally with:

```bash
pnpm test
```
